# SRS v4 superseded by MVP and Advanced split

The monolithic SRS v4.0 (Draft) is superseded by `SRS_v4_MVP.md` (Approved) and `SRS_v4_Advanced.md` (Approved). The original parent file was removed at implementation handoff — all new work references the split documents only.

**Why:** The split documents have approved status, explicit phase boundaries, and are the source for all downstream specs. The parent draft creates ambiguity about which requirements are canonical.
