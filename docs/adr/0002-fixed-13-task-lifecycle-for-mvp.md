# Fixed 13-task lifecycle for MVP

Every accepted case generates the same 13 standard tasks in a fixed order with defined prerequisite gates. Custom tasks (up to 5 per case) may be added by administrators but do not alter the default prerequisite logic.

**Why:** The firm currently follows a single workflow in Excel. A configurable per-application-type lifecycle would require seed data management, admin UI, and validation logic that doubles M3 complexity. The SRS implies a fixed list; flexibility is deferred to a future phase.

**Future:** Config-driven task lists per application type when the firm requests different workflows.
