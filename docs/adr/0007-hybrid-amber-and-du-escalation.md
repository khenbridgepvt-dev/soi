# Hybrid amber thresholds and document upload escalation

**General tasks (task board colours):** Amber ("approaching deadline") triggers on **whichever comes first**:
1. **Calendar proximity** — deadline within 3 calendar days, OR
2. **Time elapsed** — 50% or more of the allocated time slot has passed without completion.

**Document Upload (DU) tasks (Tasks 12 & 13):** The 3-day rule uses **working days**, not calendar days. When an appointment date is set (Task 11), the system calculates the upload window (3 working days before appointment).

- At **3 working days before** the upload window: in-app notification to assigned staff and admin that document upload is approaching.
- If Task 12 or 13 remains incomplete after that point: **escalating urgency** — repeat notifications each working day with increasing severity (warning → critical), and task rows progress amber → red on the task board until completed.

Full appointment safety net automation (auto-schedule Task 13, 14/7/1-day tiers, countdown badges) remains Advanced (US-12.x). Core DU approaching alerts are MVP.
