# Task 8 unlimited revisions with admin visibility

Task 8 (Senior Review) revision loops are **unlimited** — there is no automatic cap. When a senior marks **Revisions Required**, Task 5 reopens as many times as needed.

The system tracks a **revision count** per case (incremented each time Task 8 returns Revisions Required). When the count reaches a configurable threshold (default: **3**), administrators receive an in-app alert: "Case [reference] has had N senior review revision cycles — review may be needed."

Admins can see the revision count on the case detail page and task board. The alert does not block further revisions.
