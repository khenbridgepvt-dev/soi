# Delivery assumptions: 1 developer, 2-week sprints

MVP delivery is planned as 8 two-week sprints (~4 months) with a single full-stack developer. RLS policies are introduced incrementally per table as modules are built, not as a Sprint 1 gate. Staging demos target every 2 sprints (Sprints 2, 4, 6, 8).

**Why:** No team size or sprint length was confirmed in the original open questions. These assumptions unblock sprint planning in `scope_matrix.md`. Adjust if team composition changes.
